LeadFlow AI 🚀

Smart CRM & Manufacturing Workflow Platform

LeadFlow AI is a modern enterprise workflow platform designed for manufacturing businesses to streamline lead management, sales tracking, dispatch operations, employee workflows, and analytics in a centralized system.

This project demonstrates scalable frontend architecture, modern React development practices, enterprise dashboard design, and real-world business workflow implementation.

⚡ Installation

Clone Repository

git clone https://github.com/GirishmaSajjarao/Leadflow-Ai.git
cd leadflow-ai




📦 Install Dependencies

Using npm:

npm install

Using bun:

bun install




▶️ Run the Project

Using npm:

npm run dev

Using bun:

bun run dev

Application runs on:

http://localhost:5173
